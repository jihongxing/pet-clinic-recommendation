## API对接

### 认证

**登录流程:**
```javascript
// 1. 获取code
wx.login({
  success: (res) => {
    const code = res.code;
    
    // 2. 发送到后端
    wx.request({
      url: `${API_BASE_URL}/auth/login`,
      method: 'POST',
      data: { code },
      success: (res) => {
        const { token, user } = res.data.data;
        
        // 3. 保存token
        wx.setStorageSync('token', token);
        wx.setStorageSync('user', user);
      }
    });
  }
});
```

**请求拦截:**
```javascript
function request(options) {
  const token = wx.getStorageSync('token');
  
  return wx.request({
    ...options,
    header: {
      'Authorization': `Bearer ${token}`,
      ...options.header
    }
  });
}
```

**当前后端联调约定:**

- `POST /api/v1/auth/login`
  - 请求体：`{ code: string }`
  - 成功响应：`{ code: 0, message: 'success', data: { token, user } }`
- `GET /api/v1/user/profile`
  - 请求头：`Authorization: Bearer <token>`
  - 成功响应：`{ code: 0, message: 'success', data: user }`
- 鉴权失败响应：
  - HTTP 状态：`401`
  - 响应体：`{ code, message, data: null, path, timestamp }`
  - 前端收到 `401` 后应清理本地 `token` 并引导重新登录
- 本地联调补充：
  - 后端已支持开发环境直连调试，可通过 `POST /api/v1/auth/dev-token` 获取临时令牌
  - `POST /api/v1/auth/login` 也支持开发环境 `code=dev:<openid>` 的 mock 登录

## 关键注意事项

### 1. 微信小程序限制

**请求域名:**
- 必须在微信公众平台配置服务器域名
- 必须使用HTTPS
- 不能使用IP地址

**文件大小:**
- 单个包不超过2MB
- 总包不超过20MB（分包）

**API限制:**
- wx.request 并发限制10个
- wx.uploadFile 并发限制10个

### 2. 用户体验

**加载状态:**
```javascript
wx.showLoading({ title: '加载中...' });
// ... 请求
wx.hideLoading();
```

**错误提示:**
```javascript
wx.showToast({
  title: '操作失败',
  icon: 'none',
  duration: 2000
});
```

**空状态:**
```xml
<view wx:if="{{clinics.length === 0}}" class="empty-state">
  <image src="/images/empty.png" />
  <text>暂无诊所数据</text>
</view>
```

### 3. 数据安全

**敏感信息:**
- 不在前端存储敏感信息
- Token使用加密存储
- 定期刷新Token

**数据验证:**
- 前端验证用户输入
- 后端再次验证
- 防止XSS攻击
