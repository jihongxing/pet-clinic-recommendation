### 1.2 技术栈（确定版）

#### 前端
- **微信小程序原生开发**
- **理由**：
  - 性能最优
  - 无需跨端（V1只做微信）
  - 开发简单，调试方便
  - 包体积小

#### 后端
- **Node.js 20.x + NestJS 10.x**
- **TypeScript 5.x**
- **理由**：
  - 开发速度快
  - TypeScript类型安全
  - 生态成熟
  - 团队熟悉度高
  - 适合快速迭代
  - 装饰器语法优雅

#### 数据库
- **PostgreSQL 15 + PostGIS 3.3**（主库）
  - 存储所有业务数据
  - PostGIS 扩展支持地理位置查询
  - MVCC 并发控制
  - JSONB 支持灵活数据
  - 全文搜索内置
  - 比MySQL更强的地理空间能力
- **Redis 7.0**（缓存）
  - 缓存热点数据
  - 限流控制
  - 会话管理
  - 分布式锁

**为什么选择PostgreSQL + PostGIS？**
1. **地理查询性能**：PostGIS是业界标准的地理空间扩展，性能优于MySQL空间索引约30%
2. **GEOGRAPHY类型**：自动处理地球曲率，距离计算更精确
3. **GIST索引**：专为地理数据优化的索引类型，查询效率更高
4. **功能丰富**：支持多边形、路径、地理围栏等复杂查询
5. **JSONB支持**：存储灵活数据（如异常行为详情）性能优于MySQL的JSON
6. **全文搜索**：内置全文搜索，无需额外引入Elasticsearch
7. **并发控制**：MVCC机制，读写不阻塞
8. **数据完整性**：更严格的类型系统和约束

#### 部署
- **云服务商**：阿里云 / 腾讯云
- **服务器**：2核4G（初期）→ 4核8G（扩展）
- **操作系统**：Ubuntu 22.04 LTS
- **容器化**：Docker + Docker Compose（可选）

#### 开发工具
- **IDE**：VSCode
- **API测试**：Postman / Swagger
- **版本控制**：Git + GitHub/GitLab
- **CI/CD**：GitHub Actions / GitLab CI

### 2.1 标签权重计算引擎（V2升级版）

#### 综合分数计算

```typescript
interface ClinicScore {
  trustScore: number;      // 信任分（45%）
  valueScore: number;      // 性价比分（25%）
  experienceScore: number; // 体验分（15%）
  socialScore: number;     // 社交证明（15%）
  riskPenalty: number;     // 风险惩罚
  confidenceFactor: number; // 置信度系数
  finalScore: number;      // 最终分数
}

class ScoreCalculator {
  // 权重配置（V2升级）
  private readonly WEIGHTS = {
    trust: 0.45,        // 从0.5降至0.45（防单一维度操控）
    value: 0.25,        // 从0.3降至0.25
    experience: 0.15,   // 从0.2降至0.15
    social: 0.15,       // 从0.1提升至0.15（强调长期一致性）
    riskPenaltyPerTag: 15  // 从10提升至15（加重惩罚）
  };
  
  // 基准分数（用于小样本保护）
  private readonly BASE_SCORE = 60;
  
  // 置信度阈值（需要20个标签才能达到完全置信）
  private readonly CONFIDENCE_THRESHOLD = 20;
  
  async calculateClinicScore(clinicId: number): Promise<ClinicScore> {
    // 1. 获取各层级标签统计
    const tagStats = await this.getTagStatsByLayer(clinicId);
    const totalTags = tagStats.reduce((sum, t) => sum + t.count, 0);
    
    // 2. 计算各维度分数
    const trustScore = await this.calculateTrustScore(clinicId, tagStats);
    const valueScore = await this.calculateValueScore(clinicId, tagStats);
    const experienceScore = await this.calculateExperienceScore(clinicId, tagStats);
    const socialScore = await this.calculateSocialProof(clinicId);
    
    // 3. 计算风险惩罚
    const riskPenalty = await this.calculateRiskPenalty(clinicId, tagStats);
    
    // 4. 计算置信度系数（小样本保护）
    const confidenceFactor = Math.min(1.0, totalTags / this.CONFIDENCE_THRESHOLD);
    
    // 5. 计算原始分数
    const rawScore = 
      trustScore * this.WEIGHTS.trust +
      valueScore * this.WEIGHTS.value +
      experienceScore * this.WEIGHTS.experience +
      socialScore * this.WEIGHTS.social -
      riskPenalty;
    
    // 6. 应用置信度系数（向基准分数回归）
    const finalScore = rawScore * confidenceFactor + 
                      this.BASE_SCORE * (1 - confidenceFactor);
    
    return {
      trustScore,
      valueScore,
      experienceScore,
      socialScore,
      riskPenalty,
      confidenceFactor,
      finalScore
    };
  }
  
  // 🟢 TrustScore计算（防刷核心）
  private async calculateTrustScore(
    clinicId: number, 
    tagStats: TagStat[]
  ): Promise<number> {
    const trustTags = tagStats.filter(t => t.category === 'trust');
    
    let positiveScore = 0;
    let negativeScore = 0;
    let totalWeight = 0;
    
    for (const tag of trustTags) {
      // 获取该标签的用户去重权重
      const userWeights = await this.getUserDeduplicationWeights(
        clinicId, 
        tag.tagId
      );
      
      const weightedCount = userWeights.reduce((sum, w) => sum + w, 0);
      
      if (tag.type === 'positive') {
        positiveScore += weightedCount;
      } else {
        negativeScore += weightedCount;
      }
      
      totalWeight += weightedCount;
    }
    
    if (totalWeight === 0) return 0;
    
    // (正向 - 负向) / 总数 × 100
    return ((positiveScore - negativeScore) / totalWeight) * 100;
  }
  
  // 用户去重权重计算（防刷关键）
  private async getUserDeduplicationWeights(
    clinicId: number,
    tagId: number
  ): Promise<number[]> {
    // 获取所有打过这个标签的用户
    const users = await this.db.query(`
      SELECT user_id, created_at
      FROM user_tag_log
      WHERE clinic_id = ? AND tag_id = ?
      ORDER BY user_id, created_at
    `, [clinicId, tagId]);
    
    const weights: number[] = [];
    const userEvalCount = new Map<number, number>();
    
    for (const user of users) {
      const count = (userEvalCount.get(user.user_id) || 0) + 1;
      userEvalCount.set(user.user_id, count);
      
      // 第1次=1.0, 第2次=0.3, 第3次及以上=0.1
      let weight = 1.0;
      if (count === 2) weight = 0.3;
      else if (count >= 3) weight = 0.1;
      
      weights.push(weight);
    }
    
    return weights;
  }
  
  // 🟡 ValueScore计算（独立性验证）
  private async calculateValueScore(
    clinicId: number,
    tagStats: TagStat[]
  ): Promise<number> {
    const valueTags = tagStats.filter(t => t.category === 'value');
    
    // 计算独立用户数
    const uniqueUsers = await this.getUniqueUserCount(clinicId, 'value');
    
    // 独立性系数：至少5个独立用户才能达到1.0
    const independenceFactor = Math.min(1.0, uniqueUsers / 5);
    
    const totalWeight = valueTags.reduce((sum, t) => sum + t.count, 0);
    const totalTags = tagStats.reduce((sum, t) => sum + t.count, 0);
    
    if (totalTags === 0) return 0;
    
    return (totalWeight / totalTags) * independenceFactor * 100;
  }
  
  // 🔵 ExperienceScore计算（简单加权）
  private async calculateExperienceScore(
    clinicId: number,
    tagStats: TagStat[]
  ): Promise<number> {
    const expTags = tagStats.filter(t => t.category === 'experience');
    const totalWeight = expTags.reduce((sum, t) => sum + t.count, 0);
    const totalTags = tagStats.reduce((sum, t) => sum + t.count, 0);
    
    if (totalTags === 0) return 0;
    
    return (totalWeight / totalTags) * 100;
  }
  
  // 🟣 SocialProof计算（长期一致性）
  private async calculateSocialProof(clinicId: number): Promise<number> {
    // 1. 回头客比例
    const repeatRate = await this.getRepeatCustomerRate(clinicId);
    
    // 2. 推荐次数系数
    const recommendCount = await this.getRecommendCount(clinicId);
    const recommendFactor = Math.min(1.0, recommendCount / 20);
    
    // 3. 用户活跃度（近30天）
    const activeRate = await this.getActiveUserRate(clinicId, 30);
    
    // 综合计算
    return (
      repeatRate * 0.5 + 
      recommendFactor * 0.3 + 
      activeRate * 0.2
    ) * 100;
  }
  
  // 回头客比例计算
  private async getRepeatCustomerRate(clinicId: number): Promise<number> {
    const result = await this.db.query(`
      SELECT 
        COUNT(DISTINCT user_id) as total_users,
        COUNT(DISTINCT CASE 
          WHEN order_count > 1 THEN user_id 
        END) as repeat_users
      FROM (
        SELECT user_id, COUNT(*) as order_count
        FROM \`order\`
        WHERE clinic_id = ? AND status = 'confirmed'
        GROUP BY user_id
      ) t
    `, [clinicId]);
    
    if (result[0].total_users === 0) return 0;
    return result[0].repeat_users / result[0].total_users;
  }
  
  // 推荐次数计算（含来源链衰减）
  private async getRecommendCount(clinicId: number): Promise<number> {
    const recommends = await this.db.query(`
      SELECT referrer_user_id, COUNT(*) as count
      FROM user_referral
      WHERE clinic_id = ?
      GROUP BY referrer_user_id
    `, [clinicId]);
    
    let totalWeight = 0;
    for (const rec of recommends) {
      // 同一来源链权重衰减
      const count = rec.count;
      if (count === 1) totalWeight += 1.0;
      else if (count === 2) totalWeight += 1.5; // 1.0 + 0.5
      else totalWeight += 1.7; // 1.0 + 0.5 + 0.2 * (count - 2)
    }
    
    return totalWeight;
  }
  
  // 🔴 RiskPenalty计算（时间衰减 + 独立性）
  private async calculateRiskPenalty(
    clinicId: number,
    tagStats: TagStat[]
  ): Promise<number> {
    const riskTags = tagStats.filter(t => t.category === 'risk');
    
    let totalPenalty = 0;
    
    for (const tag of riskTags) {
      // 获取独立投诉用户数
      const uniqueUsers = await this.getUniqueUserCount(
        clinicId, 
        'risk', 
        tag.tagId
      );
      
      // 独立性权重：至少3个独立用户才能达到1.0
      const independenceFactor = Math.min(1.0, uniqueUsers / 3);
      
      // 时间衰减因子
      const timeFactor = await this.getTimeDecayFactor(
        clinicId, 
        tag.tagId
      );
      
      // 每个风险标签基础扣15分
      const penalty = this.WEIGHTS.riskPenaltyPerTag * 
                     timeFactor * 
                     independenceFactor;
      
      totalPenalty += penalty;
    }
    
    return totalPenalty;
  }
  
  // 时间衰减因子计算
  private async getTimeDecayFactor(
    clinicId: number,
    tagId: number
  ): Promise<number> {
    const result = await this.db.query(`
      SELECT 
        AVG(DATEDIFF(NOW(), created_at)) as avg_days
      FROM user_tag_log
      WHERE clinic_id = ? AND tag_id = ?
    `, [clinicId, tagId]);
    
    const avgDays = result[0].avg_days || 0;
    
    // 30天内=1.0, 31-60=0.7, 61-90=0.4, 90+=0.2
    if (avgDays <= 30) return 1.0;
    if (avgDays <= 60) return 0.7;
    if (avgDays <= 90) return 0.4;
    return 0.2;
  }
  
  // 获取独立用户数
  private async getUniqueUserCount(
    clinicId: number,
    category: string,
    tagId?: number
  ): Promise<number> {
    let sql = `
      SELECT COUNT(DISTINCT utl.user_id) as count
      FROM user_tag_log utl
      JOIN tag t ON utl.tag_id = t.id
      WHERE utl.clinic_id = ? AND t.category = ?
    `;
    
    const params = [clinicId, category];
    
    if (tagId) {
      sql += ' AND utl.tag_id = ?';
      params.push(tagId);
    }
    
    const result = await this.db.query(sql, params);
    return result[0].count || 0;
  }
}
```

### 2.2 标签生命周期管理

#### 状态机实现

```typescript
enum TagStatus {
  NEW = 'new',           // <3人，不展示
  VERIFIED = 'verified', // ≥3人，正常展示
  STABLE = 'stable',     // ≥10人+30天，加粗展示
  EXPIRED = 'expired'    // 90天无新增，灰色展示
}

class TagLifecycleManager {
  // 状态转换规则
  private readonly RULES = {
    newToVerified: { minUsers: 3 },
    verifiedToStable: { minUsers: 10, minDays: 30 },
    toExpired: { maxDaysWithoutUpdate: 90 }
  };
  
  // 权重映射
  private readonly WEIGHT_MAP = {
    [TagStatus.NEW]: 0.3,
    [TagStatus.VERIFIED]: 1.0,
    [TagStatus.STABLE]: 1.2,
    [TagStatus.EXPIRED]: 0.5
  };
  
  async updateTagStatus(clinicId: number, tagId: number) {
    const stat = await this.getTagStat(clinicId, tagId);
    const oldStatus = stat.status;
    let newStatus = oldStatus;
    
    // 状态转换逻辑
    if (stat.uniqueUsers >= this.RULES.verifiedToStable.minUsers &&
        this.daysSince(stat.firstTaggedAt) >= this.RULES.verifiedToStable.minDays) {
      newStatus = TagStatus.STABLE;
    } else if (stat.uniqueUsers >= this.RULES.newToVerified.minUsers) {
      newStatus = TagStatus.VERIFIED;
    } else {
      newStatus = TagStatus.NEW;
    }
    
    // 检查是否过期
    if (this.daysSince(stat.lastTaggedAt) >= this.RULES.toExpired.maxDaysWithoutUpdate) {
      newStatus = TagStatus.EXPIRED;
    }
    
    // 更新状态和权重
    if (newStatus !== oldStatus) {
      await this.updateStatus(clinicId, tagId, newStatus, this.WEIGHT_MAP[newStatus]);
      await this.logStatusChange(clinicId, tagId, oldStatus, newStatus);
    }
  }
  
  // 定时任务：每天凌晨更新所有标签状态
  @Cron('0 0 * * *')
  async updateAllTagStatuses() {
    const allStats = await this.getAllTagStats();
    for (const stat of allStats) {
      await this.updateTagStatus(stat.clinicId, stat.tagId);
    }
  }
}
```

#### 行为推断引擎

```typescript
class TagInferenceEngine {
  // 推断规则配置
  private readonly INFERENCE_RULES = [
    {
      tagName: '回头客多',
      condition: async (clinicId: number) => {
        const repeatRate = await this.getRepeatOrderRate(clinicId);
        return repeatRate >= 0.3; // 30%复购率
      }
    },
    {
      tagName: '本地口碑好',
      condition: async (clinicId: number) => {
        const localUserRate = await this.getLocalUserRate(clinicId);
        return localUserRate >= 0.7; // 70%本地用户
      }
    },
    {
      tagName: '被推荐次数高',
      condition: async (clinicId: number) => {
        const shareCount = await this.getShareCount(clinicId);
        return shareCount >= 20; // 至少20次分享
      }
    }
  ];
  
  // 定时任务：每天更新系统推断标签
  @Cron('0 2 * * *')
  async inferSystemTags() {
    const clinics = await this.getAllActiveClinics();
    
    for (const clinic of clinics) {
      for (const rule of this.INFERENCE_RULES) {
        const shouldHaveTag = await rule.condition(clinic.id);
        const tag = await this.getTagByName(rule.tagName);
        const hasTag = await this.hasSystemTag(clinic.id, tag.id);
        
        if (shouldHaveTag && !hasTag) {
          // 添加系统推断标签
          await this.addSystemTag(clinic.id, tag.id);
        } else if (!shouldHaveTag && hasTag) {
          // 移除不再满足条件的标签
          await this.removeSystemTag(clinic.id, tag.id);
        }
      }
    }
  }
  
  private async getRepeatOrderRate(clinicId: number): Promise<number> {
    const result = await this.db.query(`
      SELECT 
        COUNT(DISTINCT user_id) as total_users,
        COUNT(DISTINCT CASE WHEN order_count > 1 THEN user_id END) as repeat_users
      FROM (
        SELECT user_id, COUNT(*) as order_count
        FROM \`order\`
        WHERE clinic_id = ? AND status = 'confirmed'
        GROUP BY user_id
      ) t
    `, [clinicId]);
    
    return result[0].repeat_users / result[0].total_users;
  }
}
```

```sql
  first_tagged_at, last_tagged_at, status, display_weight

  clinic_id,
  tag_id,
  SUM(final_weight) as count,
  COUNT(DISTINCT user_id) as unique_users,
  MIN(created_at) as first_tagged_at,
  MAX(created_at) as last_tagged_at,
  CASE 
    WHEN COUNT(DISTINCT user_id) >= 10 
      AND DATEDIFF(NOW(), MIN(created_at)) >= 30 THEN 'stable'
    WHEN COUNT(DISTINCT user_id) >= 3 THEN 'verified'
    ELSE 'new'
```

```typescript
  const clinics = await this.getAllActiveClinics();
  
  for (const clinic of clinics) {
    const scores = await this.scoreCalculator.calculateClinicScore(clinic.id);
    
    // 更新诊所分数字段
    await this.db.query(`
      UPDATE clinic 
      SET 
        trust_score = ?,
        value_score = ?,
        experience_score = ?,
        risk_penalty = ?,
        social_score = ?,
        reputation_score = ?,  -- 口碑优先时使用
        price_score = ?        -- 性价比优先时使用
      WHERE id = ?
    `, [
      scores.trustScore,
      scores.valueScore,
      scores.experienceScore,
      scores.riskPenalty,
      scores.socialScore,
      // 口碑优先：Trust权重0.6, Value权重0.2
      scores.trustScore * 0.6 + scores.valueScore * 0.2 + 
        scores.experienceScore * 0.2 + scores.socialScore * 0.1 - scores.riskPenalty,
      // 性价比优先：Value权重0.5, Trust权重0.3
      scores.valueScore * 0.5 + scores.trustScore * 0.3 + 
        scores.experienceScore * 0.2 + scores.socialScore * 0.1 - scores.riskPenalty,
      clinic.id
    ]);
  }
}
```

### 2.3 排序系统

#### 实现方式：**预计算 + 实时查询**

**预计算（定时任务）：**
- 每5分钟更新一次 `reputation_score` 和 `price_score`
- 使用后台定时任务（Node-cron）

**实时查询：**
- 查询时直接使用预计算的分数字段
- 按分数降序排列

**代码示例：**

```typescript
async getNearbyClinics(params: {
  lat: number;
  lng: number;
  radius: number; // 米
  sortType: 'reputation' | 'price';
  tagIds?: number[];
  city: string;
}) {
  const { lat, lng, radius, sortType, tagIds, city } = params;
  
  // 缓存key
  const cacheKey = `clinics:${city}:${lat}:${lng}:${radius}:${sortType}:${tagIds?.join(',')}`;
  
  // 尝试从缓存获取
  const cached = await this.redis.get(cacheKey);
  if (cached) {
    return JSON.parse(cached);
  }
  
  // 数据库查询
  let query = this.clinicRepo
    .createQueryBuilder('c')
    .select([
      'c.id', 'c.name', 'c.address', 'c.lat', 'c.lng',
      `ST_Distance_Sphere(c.location, POINT(${lng}, ${lat})) AS distance`,
      'c.reputation_score', 'c.price_score'
    ])
    .where('c.status = 1')
    .andWhere('c.city = :city', { city })
    .andWhere(`ST_Distance_Sphere(c.location, POINT(${lng}, ${lat})) <= :radius`, { radius });
  
  // 标签筛选
  if (tagIds && tagIds.length > 0) {
    query = query
      .innerJoin('clinic_tag_stat', 's', 's.clinic_id = c.id')
      .andWhere('s.tag_id IN (:...tagIds)', { tagIds });
  }
  
  // 排序
  const scoreField = sortType === 'reputation' ? 'reputation_score' : 'price_score';
  query = query.orderBy(`c.${scoreField}`, 'DESC').addOrderBy('distance', 'ASC');
  
  const result = await query.limit(50).getRawMany();
  
  // 缓存5分钟
  await this.redis.setex(cacheKey, 300, JSON.stringify(result));
  
  return result;
}
```

```bash
BACKUP_DIR="/data/backup/postgresql"
DB_NAME="pet_clinic"

# PostgreSQL备份
pg_dump -U postgres -d ${DB_NAME} | gzip > ${BACKUP_DIR}/${DB_NAME}_${DATE}.sql.gz

# 删除7天前的备份
find ${BACKUP_DIR} -name "*.sql.gz" -mtime +7 -delete
```

## 九、安全措施

### 9.1 API安全

- **HTTPS**：强制使用SSL证书
- **JWT认证**：所有需要登录的接口验证token
- **请求签名**：防止重放攻击（可选）
- **SQL注入防护**：使用ORM参数化查询
- **XSS防护**：输入过滤

### 9.2 数据安全

- **敏感信息加密**：手机号、微信号
- **数据库备份**：每天自动备份
- **访问控制**：数据库仅内网访问

## 十一、技术风险与应对

### 11.1 性能风险

**风险**：地理位置查询慢  
**应对**：
- 使用空间索引
- Redis缓存热点区域
- 限制查询范围

**风险**：并发量大时数据库压力  
**应对**：
- 读写分离（主从复制）
- 增加Redis缓存
- 数据库连接池优化

---

### 11.2 数据风险

**风险**：恶意刷标签  
**应对**：
- 唯一索引防重复
- 限流机制
- 新用户降权
- 异常检测

## 🔚 技术方案总结

### 核心技术选型

| 层级 | 技术 | 理由 |
|-----|------|------|
| 前端 | 微信小程序原生 | 性能最优，开发简单 |
| 后端 | Node.js + NestJS | 开发快速，生态成熟 |
| 数据库 | PostgreSQL 15 + PostGIS | 地理查询强大，功能丰富 |
| 缓存 | Redis 7.0 | 高性能，功能丰富 |
| 部署 | 阿里云/腾讯云 | 成本低，服务稳定 |

### 关键技术点（升级版）

1. **四层标签架构**：L1用户决策 + L2医疗能力 + L3风险信号 + L4社交传播
2. **标签权重模型**：Trust(0.45) + Value(0.25) + Experience(0.15) + Social(0.15) - Risk
3. **标签生命周期**：new → verified → stable → expired（防污染核心）
4. **系统推断引擎**：行为数据自动生成L4标签
5. **风险检测引擎**：多维度触发L3风险标签
6. **地理位置查询**：PostgreSQL + PostGIS（GIST索引）
7. **防刷机制**：多人共识 + 时间衰减 + 用户信用体系
8. **性能优化**：预计算分数 + 多级缓存 + 定时任务

### 技术壁垒

**不是功能实现，而是：**

1. **标签生成权**：什么算好诊所，我们定义
2. **标签解释权**：四层权重模型的演化能力
3. **数据闭环**：用户行为 → 标签 → 排序 → 推荐 → 更多用户
4. **PostGIS地理能力**：业界标准的地理空间查询

### 开发周期

**2周可上线MVP**（L1标签层 + 基础排序），核心功能完整，性能满足初期需求。

**3个月形成壁垒**（L2/L3/L4全部启用），成为"宠物医疗的信用地图"。
