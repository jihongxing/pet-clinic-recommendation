# 小程序提审前说明

## 目标

这份文档用于给微信小程序提审前做统一口径整理，避免出现：

- 审核说明写得太空
- 测试路径不清楚
- 域名、账号、功能边界说不明白

## 1. 产品定位

本项目是一个帮助宠物主人快速查看附近宠物诊所、浏览结构化评价并完成轻量预约动作的小程序。

它不是：

- 在线问诊平台
- 药品销售平台
- 支付平台
- 医疗结论生成工具

当前核心目标是帮助用户做“去哪家诊所更靠谱”的信息决策。

## 2. 当前主链路

提审时建议重点展示这一条路径：

1. 小程序启动
2. 微信登录
3. 首页展示附近诊所列表
4. 进入诊所详情页
5. 点击电话/微信预约动作
6. 完成标签评价
7. 在“我的”里查看预约与评价记录

## 3. 建议审核说明文案

可以直接使用下面这段：

```text
本小程序用于帮助宠物主人查看附近宠物诊所的结构化评价信息，支持浏览诊所列表、查看诊所详情、记录电话/微信预约动作，并提交就诊体验标签反馈。小程序不提供在线支付、不提供互联网诊疗、不销售药品，主要功能为信息展示与用户反馈记录。
```

## 4. 建议审核测试路径

可以直接按下面的步骤提交：

```text
1. 进入首页，允许定位
2. 查看附近诊所列表
3. 点击任一诊所进入详情页
4. 点击“电话预约”或“微信预约”
5. 返回后进入评价页，选择情绪和标签并提交
6. 进入“我的”页面，查看预约记录和我的评价
```

## 5. 服务器与域名说明

提审前需要确认微信公众平台已配置：

- `request 合法域名`
- `uploadFile 合法域名`
- `downloadFile 合法域名`

当前建议配置的域名为：

- `https://api-staging.petmed.example.com`
- `https://api.petmed.example.com`

注意：

- 只能填域名，不能带路径
- 必须是 HTTPS
- 不能使用 IP

## 6. 审核前自查清单

### 功能自查

- 微信登录可成功返回 token
- 首页能正常返回附近诊所列表
- 详情页能展示基础信息和标签聚合
- 预约动作能正常创建记录
- 标签评价可正常提交
- “我的预约”和“我的评价”可正常查看

### 稳定性自查

- `trial` 包 API 域名已切到 HTTPS staging 域名
- 后端 `/api/v1/health` 正常
- Nginx HTTPS 证书有效
- 关键接口没有明显 4xx / 5xx
- Grafana 中错误率和日志面板无持续异常

### 文案与合规自查

- 没有“在线问诊”“治疗建议”“保证疗效”这类风险表述
- 没有支付入口
- 没有药品交易能力
- 用户评价文案不过度引导、不承诺排名收费

## 7. 当前仍建议补齐的项

如果是正式提审而不是内部预审，建议至少再确认：

- 真机完整走一遍主链路
- 准备审核专用测试账号
- 准备至少 1 份审核备注文案
- 准备 2 到 3 张功能截图

## 8. 建议提审材料包

建议你最终整理成这几样：

1. 小程序审核说明
2. 测试路径
3. 测试账号
4. 合法域名截图
5. 首页 / 详情 / 评价 / 我的 页面截图
