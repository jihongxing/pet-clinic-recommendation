# 本地环境配置说明

## 1. 文件说明

项目现在使用两层环境变量模板：

- 根目录 [.env.example](D:/codeSpace/petMed/.env.example)
  - 给 `podman compose` / `docker compose` 使用
  - 影响 PostgreSQL、backend 容器注入

- 后端目录 [backend/.env.example](D:/codeSpace/petMed/backend/.env.example)
  - 给本地直接运行 `npm run start:dev` 使用
  - 影响 NestJS 应用读取配置

---

## 2. 容器方式启动

如果你用 `podman compose`：

1. 在仓库根目录复制模板

```powershell
Copy-Item .env.example .env
```

2. 按需修改以下字段：

- `DB_USERNAME`
- `DB_PASSWORD`
- `DB_DATABASE`
- `JWT_SECRET`
- `WECHAT_APPID`
- `WECHAT_SECRET`

3. 启动：

```powershell
podman compose up -d
```

说明：

- 如果暂时不做微信登录联调，`WECHAT_APPID` 和 `WECHAT_SECRET` 可以先留空

---

## 3. 本地直接运行后端

如果你直接在本机运行后端：

1. 在 `backend/` 目录复制模板

```powershell
Copy-Item .env.example .env
```

2. 如果数据库和 Redis 通过容器映射到本机端口，推荐使用：

```env
DB_HOST=localhost
DB_PORT=5432
REDIS_HOST=localhost
REDIS_PORT=6379
```

3. 启动：

```powershell
cd backend
npm run start:dev
```

---

## 4. 当前阶段哪些变量必须填

本阶段最小必填项：

- `DB_USERNAME`
- `DB_PASSWORD`
- `DB_DATABASE`
- `JWT_SECRET`

当前可留空：

- `WECHAT_APPID`
- `WECHAT_SECRET`

---

## 5. 当前推荐默认值

开发阶段推荐：

```env
DB_USERNAME=postgres
DB_PASSWORD=postgres_password
DB_DATABASE=pet_clinic_recommendation
JWT_SECRET=dev_only_change_me
```

---

## 6. 当前常用检查命令

后端本地检查：

```powershell
cd backend
npm run check
```

如果本地 PostgreSQL 和 Redis 已启动，还可以执行：

```powershell
cd backend
npm run check:data
```

前端本地检查：

```powershell
cd frontend
npm run check
```
